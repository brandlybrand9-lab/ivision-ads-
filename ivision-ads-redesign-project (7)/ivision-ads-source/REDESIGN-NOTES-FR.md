# Refonte iVISION ADS — version inspirée d’Adrova

Cette version reprend de beaucoup plus près la structure et la direction visuelle du modèle Adrova : fond presque noir, grande accroche centrée, badge de confiance, composition de cartes d’analytics, bandeau de plateformes, cartes illustrées de services, framework de croissance, résultats, témoignages, études de cas, FAQ et appel à l’action.

L’identité iVISION ADS est conservée : logo, contenu métier, version arabe RTL par défaut, et palette **bleu `#2563EB`, noir et blanc** à la place de l’accent orange d’Adrova. Les versions anglaise et française restent accessibles via le sélecteur de langue.

## Vérifications

La compilation Vite et la vérification TypeScript passent :

```bash
npm run build
npm run lint
```

## Tester le projet

```bash
npm ci
npm run dev
```

Cette copie source et son aperçu ne sont pas publiés sur `ivisionads.online`. Pour remplacer le site public, il faut intégrer ces fichiers au dépôt de production puis les déployer sur l’hébergement du site.
